# Support

BranchHarbor is community-maintained alpha software.

- Use GitHub Discussions for setup questions and design conversations when enabled.
- Use GitHub Issues for reproducible bugs and scoped feature requests.
- Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.

Before requesting support, run:

```bash
pnpm release:tree
make status
make check
```

Remove credentials, cookies, repository contents, and personal data from logs. There is currently no paid support channel or guaranteed response time.
